Реквизиты и элементы формы

• Страницы (ГруппаСтраницы):
	1. СтраницаЖурналы — просмотр лога и создание масок.
	2. СтраницаМаски — динамический список Справочник.ЕРП_МаскиМониторингаЛогов.
	3. СтраницаГруппы — динамический список Справочник.ЕРП_ГруппыПолучателейУведомлений.
	4. СтраницаПривязкиTG — динамический список РегистрСведений.ЕРП_ПривязкиTelegram.
	5. СтраницаОчередь — динамический список РегистрСведений.ЕРП_ОчередьУведомлений (с кнопками «Повторить отправку ошибочных» и «Очистить отправленные»).
• Реквизиты формы для вкладки СтраницаЖурналы:
	• ПутьКФайлуЛога (Строка) — поле выбора файла на сервере или из списка путей уже настроенных масок.
	• КоличествоСтрокХвоста (Число, по умолчанию 500) — чтобы не вешать клиент при открытии больших файлов.
	• ТекстЖурнала (ТекстовыйДокумент) — поле текстового документа (ТолькоПросмотр = Истина) для выделения фрагмента мышью.
• Команды:
	• ПрочитатьЖурнал — загружает последние N строк выбранного файла с сервера.
	• СоздатьМаскуПоВыделенному — забирает Элементы.ТекстЖурнала.ВыделенныйТекст и открывает форму нового элемента ЕРП_МаскиМониторингаЛогов.
