В стандартную форму списка регистра добавляется кнопка «Проверить связь (Отправить тест)», которая берет текущую строку списка (Элементы.Список.ТекущиеДанные) и вызывает ЕРП_УведомленияTelegram.ОтправитьСообщение(...), выводя пользователю либо подтверждение доставки, либо точный текст description из ответа Telegram API.

Реквизиты и команды формы

Реквизиты формы

1. Список (Основной реквизит, тип: ДинамическийСписок)
	• Основная таблица: РегистрСведений.ЕРП_ПривязкиTelegram.
	• Произвольный запрос: Ложь.
2. ОтборПользователь (тип: ОпределяемыйТип.ЕРП_ПолучательУведомлений) — фильтр по сотруднику.
3. ОтборБот (тип: ОпределяемыйТип.ЕРП_БотTelegram) — фильтр по боту UBT.
4. ОтборТолькоАктивные (тип: Булево, значение по умолчанию: Истина) — скрывает отключенные привязки.

Команды формы

• ПроверитьСвязьTelegram
	• Заголовок: Проверить связь (Тест)
	• Подсказка: Отправить тестовое сообщение в выбранный чат Telegram
	• Действие: ПроверитьСвязьTelegram

3. Правила поведения и валидации

1. Удобство массового заполнения: В таблице Список включен режим ВводитьВСтроку (редактирование прямо в ячейках таблицы). При добавлении новой строки флаг Активна автоматически устанавливается в Истина через событие списка ПриНачалеРедактирования.
2. Валидация ChatID: При изменении ячейки ChatID выполняется автоматическая очистка пробелов (СокрЛП) и проверка формата (строка должна состоять только из цифр и опционального ведущего знака - для групповых чатов и супергрупп).
3. Защита от дублирования: Поскольку Пользователь и Бот являются измерениями регистра сведений ЕРП_ПривязкиTelegram, платформа 1С автоматически блокирует запись дубля по паре (Пользователь, Бот) на уровне СУБД. При попытке записать дубль пользователю выводится понятное предупреждение.
4. Проверка связи (Тест):
	• Кнопка «Проверить связь (Тест)» берет текущую выделенную строку списка (Элементы.Список.ТекущиеДанные).
	• Если строка находится в режиме редактирования и еще не записана, форма сначала сохраняет строку (Элементы.Список.ЗакончитьРедактированиеСтроки(Ложь)).
	• На сервере вызывается адаптер ЕРП_УведомленияTelegram.ОтправитьСообщение(Бот, ChatID, ТекстТеста).
	• При успешной отправке (ok = true) выводится всплывающее оповещение о доставке; при ошибке (ok = false или сетевой сбой) — модальное предупреждение с точным кодом и текстом description от Telegram API (например, «Forbidden: bot was blocked by the user» или «Bad Request: chat not found»).
5. Условное оформление: Неактивные строки (Список.Активна = Ложь) выделяются серым цветом текста для визуального отличия от действующих привязок.
