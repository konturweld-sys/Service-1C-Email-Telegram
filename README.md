# Service-1C-Email-Telegram

Рабочий комплект службы мониторинга логов 1С и серверных адаптеров уведомлений Email/Telegram.

## Уже добавлено

- `Project/1C_Modules/ЕРП_УведомленияEmail.bsl` — переданный пользователем серверный Email-адаптер.
- `Project/1C_Modules/ЕРП_ОбработкаОчередиУведомлений.bsl` — переданная финальная редакция обработчика очереди с трёхфазной моделью аренды и UUID владельца.

PDF-распечатки из исходного `Project.zip` сохранены отдельно для сверки; они не заменяют редактируемые исходники.
