# Service-1C-Email-Telegram

Рабочий комплект службы мониторинга логов 1С и серверных адаптеров уведомлений Email/Telegram.

## Исходники, перенесённые в репозиторий

- `Project/Program.cs` — точка входа службы.
- `Project/OneCIntegrationService.csproj` — проект .NET Worker.
- `Project/Models/` — COM-контракты и настройки.
- `Project/Services/` — COM-клиент, мониторинг файлов и парсер логов.
- `Project/Scripts/` — установка, обновление и удаление службы.
- `Project/appsettings.json` — шаблон настроек без строки подключения и секретов.
- `Project/1C_Modules/ЕРП_УведомленияEmail.bsl` — серверный Email-адаптер.
- `Project/1C_Modules/ЕРП_ОбработкаОчередиУведомлений.bsl` — обработчик очереди с трёхфазной моделью аренды.
- `Project/_source_archive/` — четыре текстовых описания реквизитов и форм, перенесённые из архива.

## Материалы, ещё не перенесённые

Оригинальные PDF-распечатки и DOCX из `_source_archive` в локальном архиве не перенесены: текущий канал загрузки в репозиторий принимает UTF-8-текст, но не передаёт локальные бинарные файлы напрямую. Их следует добавить отдельной загрузкой через GitHub, если требуется хранить оригиналы в репозитории.
